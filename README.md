# FlexGlove — перчатка-интерфейс на гибких сенсорах

Учебный проект ТПУ (проектная деятельность, осень 2026). Перчатка с гибкими сенсорами на пальцах передаёт
состояние пальцев на ESP32, та — по Bluetooth на ПК. ПК-приложение показывает руку, позволяет
привязать жест к действию и выполняет это действие в тестовом интерфейсе.

| Часть | Папка | Ответственный |
|---|---|---|
| Сенсоры и схема | `hardware/` (появится) | Лиза |
| Прошивка ESP32 | `firmware/` | Захар |
| ПК-приложение (backend, обработка, ML, интерфейс) | `host/` | Данила |
| Документация, решения, план | `docs/` | все |

## Текущее состояние — v0.1.0 (этап 0)

- приём данных по **Bluetooth LE**, по **последовательному порту** (USB или Bluetooth Classic) и в **демо-режиме** без железа;
- автоматическое распознавание формата: строки `00/01/10/11`, маска числом, пакеты протокола v0.1 (см. [docs/protocol.md](docs/protocol.md));
- схема руки в реальном времени, настройка «какой канал на каком пальце»;
- привязка комбинации пальцев к одному из трёх действий: **фонарик, глаз, вентилятор**;
- защита от дребезга: жест срабатывает, если удерживается ≥ 150 мс (настраивается);
- главный экран с объектами и журналом действий; настройки и привязки сохраняются в SQLite.

## Быстрый старт

### Windows — основной вариант
1. Нужен Python 3.10+ (если нет: `winget install Python.Python.3.12` или python.org с галочкой «Add python.exe to PATH»).
2. Двойной щелчок по **`FlexGlove.bat`** (с перчаткой) или **`FlexGlove-demo.bat`** (демо без железа).
3. Первый запуск 1–2 минуты: создаётся окружение `.venv`, пакеты ставятся из папки `wheels/` без интернета
   (папка есть в сборке `FlexGlove-Windows.zip`; без неё пакеты скачаются из интернета).
4. Интерфейс откроется **отдельным окном** (Edge/Chrome в режиме приложения). Чёрное окно консоли не закрывайте — это сервер приложения.

Если Windows пишет «Система Windows защитила ваш компьютер» — «Подробнее» → «Выполнить в любом случае»
(или «Свойства» файла → «Разблокировать»).

### Вручную (Windows / macOS / Linux)
```bash
cd host
python -m venv .venv
.venv\Scripts\activate          # macOS/Linux: source .venv/bin/activate
pip install -r ../requirements.txt
python -m flexglove --demo
```
Параметры: `--demo`, `--port 8000` (если занят — берётся следующий свободный), `--ui app|browser|none`, `--db путь.db`.

### Подключение перчатки

1. **Bluetooth LE** (ESP32-S3 умеет только BLE): «Настройки» → «Bluetooth LE» → «Найти устройства» → «Подключить».
   Приложение само подписывается на все notify-характеристики устройства, знать UUID не нужно.
   Перчатку **не нужно** сопрягать в настройках Windows. Нужны Windows 10 (1809+) или 11 и включённый Bluetooth.
   *macOS:* при первом поиске система спросит разрешение на Bluetooth для Терминала/IDE.
2. **Порт**: USB-кабель или Bluetooth Classic (BluetoothSerial на обычном ESP32 — после сопряжения в системе появится
   порт `COMx` на Windows — берите исходящий из двух «Стандартный последовательный порт по Bluetooth»,
   на macOS — `/dev/cu.<имя>`). Каждая строка — одно сообщение.
3. **Демо**: имитация без железа, комбинации — кнопками или клавишами `0–3`.

Если перчатка шлёт что-то непонятное — откройте «Настройки → Отладка потока»: там видно последнее сырое сообщение,
частоту и счётчик нераспознанных сообщений.

## Структура

```
host/flexglove/
  __main__.py        запуск (python -m flexglove)
  app.py             FastAPI: REST /api/* и WebSocket /ws
  engine.py          ядро: дребезг, привязки, состояние, рассылка в интерфейс
  parser.py          разбор сообщений от перчатки (все форматы)
  storage.py         SQLite: привязки и настройки (data/flexglove.db)
  actions.py         справочник действий
  sources/           ble.py, serial_src.py, mock.py
  web/               интерфейс: index.html, app.js, hand.js, style.css
host/tests/          pytest
firmware/examples/   эталонный скетч ESP32 для проверки связи
tools/               сборка Windows-архива с офлайн-пакетами
FlexGlove.bat        запуск на Windows (FlexGlove-demo.bat — демо-режим)
docs/                протокол, архитектура, план, решения, материалы для Cowork
```

## Разработка

```bash
cd host
pip install -r ../requirements-dev.txt
python -m pytest -q
```

- ветка на задачу/этап: `stage-1-protocol`, `fix-ble-reconnect`; в `main` — через pull request;
- сообщения коммитов: `host: приём пакетов v0.1`, `firmware: заглушка сигнала`, `docs: протокол v0.1`;
- менять формат обмена — только вместе с [docs/protocol.md](docs/protocol.md) и номером версии;
- демо-режим должен работать всегда: это и среда разработки, и запасной вариант на защите.

План работ — [docs/roadmap.md](docs/roadmap.md), принятые решения — [docs/decisions.md](docs/decisions.md).
