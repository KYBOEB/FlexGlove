1. Подключение

ESP32-S3 работает только по BLE. Включите Bluetooth на компьютере, нажмите «Найти», выберите перчатку. Сопрягать в настройках Windows не нужно.

    USB-кабель или Bluetooth Classic (BluetoothSerial на обычном ESP32). Windows: после сопряжения появятся COM-порты «Стандартный последовательный порт по Bluetooth» — берите исходящий.

    Имитация перчатки (сигнал похож на реальный: АЦП ≈ 213 в покое, шум, выбросы, 50 Гц) и MPU6050.

    2. Каналы и пальцы

    Для каждого канала: какой палец и его роль. Сжатие — палец ведёт захват (среднее сгибов таких пальцев). Команды — палец участвует в жестах. Пока управление активно, пальцы сжатия из жестов исключаются, а команда срабатывает удержанием ≥ 1 с и только если пальцы сжатия при этом неподвижны.

    Рука
    MPU6050 закреплён

    Оси руки: X — к пальцам, Z — от тыльной стороны кисти. Выберите, куда смотрит ось X модуля (стрелка на плате) и какой стороной он приклеен; по умолчанию X — к пальцам, лицом от кожи.

    3. Жесты-команды

    Все сочетания согнутых пальцев. Покажите жест — его карточка подсветится; выберите команду. Одна команда — одно сочетание. «Ладонь раскрыта» — покой, не привязывается.
