1. Подключение

ESP32-S3 поддерживает только BLE. Включите Bluetooth на компьютере, нажмите «Найти», выберите перчатку и подключитесь. Сопрягать перчатку в настройках Windows не нужно.

    USB-кабель или Bluetooth Classic (BluetoothSerial на обычном ESP32). Windows: после сопряжения перчатки в «Параметры → Bluetooth» появятся COM-порты «Стандартный последовательный порт по Bluetooth» — выбирайте исходящий (обычно первый из двух).

    Имитация перчатки без железа — для разработки и запасного варианта демонстрации.
