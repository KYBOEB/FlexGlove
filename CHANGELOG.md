# Изменения

## 0.1.1 — 18.10.2026
- Windows как основная платформа: `FlexGlove.bat` / `FlexGlove-demo.bat` — первый запуск сам создаёт окружение
  и ставит пакеты из папки `wheels/` без интернета.
- Интерфейс на Windows открывается отдельным окном (Edge/Chrome в режиме приложения).
- Автовыбор свободного порта, если 8000 занят.
- Подсказки для Windows (BLE без сопряжения, COM-порты Bluetooth Classic).
- CI: тесты на Windows и Linux, проверка BLE-бэкенда WinRT.

## 0.1.0 — 18.10.2026 (этап 0)
- ПК-приложение: FastAPI + веб-интерфейс, запуск `python -m flexglove`.
- Источники: Bluetooth LE (подписка на все notify), последовательный порт (USB / BT Classic), демо-режим.
- Автоопределение формата сообщений: строки битов, маска числом, пакеты протокола v0.1.
- Схема руки, настройка соответствия каналов пальцам.
- Привязка комбинаций к действиям (фонарик, глаз, вентилятор), защита от дребезга, журнал действий.
- SQLite для привязок и настроек; тесты pytest; CI на GitHub Actions.
- Эталонный скетч ESP32 `firmware/examples/ble_bits_demo`.
