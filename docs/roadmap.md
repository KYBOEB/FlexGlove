## Этап 1 — подробно (черновик для чата этапа)

1. Связь с перчаткой Захара по BLE на реальном железе; разбор того, что она реально шлёт (отладка потока).
2. Приём пакетов v0.1 (уже поддерживается парсером) и отображение напряжений: графики 2 каналов в реальном времени.
3. Запись сессии в файл (`data/recordings/*.csv`: t_host, t_ms, seq, bits, v1…vn) кнопкой «Запись».
4. Источник `ReplaySource`: воспроизведение записанного файла через тот же конвейер.
5. Статистика: частота, потери по `seq`, задержка.
6. Пороги «согнут/разогнут» на ПК по напряжениям (с гистерезисом) — чтобы не зависеть от порогов в прошивке.
7. Тесты на всё новое; README и протокол обновлены.
