# План по этапам

**Направление:** носимый интерфейс телеуправления (продукт 2 из аналитики команды) — перчатка управляет
захватом через безопасный контроллер; жесты-комбинации — дискретные команды. С 01.11 в составе прототипа —
**MPU6050** (акселерометр + гироскоп): ориентация кисти в пространстве и 3D-модель руки в приложении.

Каждый этап = отдельный чат в проекте Claude «FlexGlove». Промпты — `docs/cowork/STAGE_KICKOFF.md`.
Планировщик (отдельный чат) обновляет этот план по отчётам этапов. Дисциплина — до 25.12.2026.

## Зависимости от команды
| Что | Кто | К какому этапу |
|---|---|---|
| Прошивка шлёт 2 значения `v1;v2` 50 Гц непрерывно | Захар | 2 |
| Запись со сгибами (протокол в docs/analysis) | Захар + Данила | 2 |
| Резистор делителя: покой — 30–50 % диапазона АЦП | Лиза | 2–3 |
| MPU6050 подключён (I²C), строка `v1;v2` + `\|` + `ax;ay;az;gx;gy;gz`, 50 Гц | Захар | 4 (формат согласовать в 2) |
| 3–5 гибких сенсоров на перчатке | Лиза | 5 |

## Риски этапов 2–4
- **Команды срабатывают от сжатия захвата** (с 2 сенсорами «оба согнуты» = и жест, и сжатие) — решается в этапе 2.
- **Рысканье (поворот вокруг вертикали) у MPU6050 дрейфует** — у датчика нет магнитометра. Наклоны (крен, тангаж)
  стабильны по гравитации; для рысканья — калибровка смещения гироскопа и кнопка «обнулить положение».
  Если рысканье критично — модуль с магнитометром (ICM-20948 / MPU9250).
- **WebGL на ноутбуке защиты** — 3D через Three.js (локально, без интернета) с запасным 2D-силуэтом.
