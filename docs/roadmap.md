# План по этапам

**Направление (с 25.10):** носимый интерфейс телеуправления (продукт 2 из аналитики команды) — перчатка
управляет захватом через безопасный контроллер. Общая платформа (5 стабильных каналов, синхронная запись,
датасеты, панель сигналов) подходит и для продукта 1 «цифровой наставник».

Каждый этап = отдельный чат в проекте Claude «FlexGlove» (см. [cowork/](cowork/)). Дисциплина — до 25.12.2026.

## Этап 2 — подробно (черновик для чата этапа)
1. С Захаром: прошивка шлёт 5 значений строкой `v1;v2;v3;v4;v5` 50 Гц, `setMTU(185)`; проверить в «Отладке потока».
2. Запись со сгибами по протоколу из `docs/analysis/2026-10-25-sensor-stream.md`; по ней — проверить пороги
   автокалибровки (30 ед.), гистерезис, задержку обработки.
3. Калибровка у 2–3 человек, сохранение профилей калибровки по пользователям (сейчас одна общая).
4. Настройка контроллера из интерфейса (мёртвая зона, скорость, ограничение сжатия) и выбор пальцев для «сжатия».
5. Тесты на новое; README/протокол обновлены.
