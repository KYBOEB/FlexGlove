## Правила проверки этапов (с 07.11)
- Этап с изменениями интерфейса закрывается только **скриншотами с компьютера Данилы** (не только тестами).
- Версия статики меняется вместе с версией приложения — браузер не должен показывать старые файлы.
- Коммиты — только от KYBOEB, без упоминаний Claude (D-29).

## Риски
- **Показ 08.11:** объём 4б большой — сначала P0 (большая 3D-рука, живое демо), потом P1.
- **Модель руки:** лицензия и качество glTF; запасной вариант — улучшенная рука из примитивов.
- **Рысканье у MPU6050 дрейфует** (нет магнитометра): только рысканье обнуляется кнопкой; наклоны — по гравитации.
- **Оси модуля на перчатке неизвестны** — пресеты крепления, фото с осями.
- **Время отсчётов — время приёма на ПК**: точные задержки требуют `millis()` с устройства (этап 5).
