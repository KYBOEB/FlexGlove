# Протокол обмена ESP32 → ПК

ПК-приложение определяет формат **автоматически** (см. `host/flexglove/parser.py`), поэтому прошивка может
переходить от v0 к v0.1 постепенно, не ломая приложение.

## v0 — текущий (этап 0): строка с битами пальцев

Одно сообщение = одна строка из символов `0`/`1`, по символу на канал. **Первый символ — канал 1.**
`0` — палец разогнут, `1` — согнут.

```
00   01   10   11
```

- BLE: значение notify-характеристики, например байты `30 31` (`"01"`); перевод строки не обязателен;
- порт (USB / Bluetooth Classic): строка с `\n` в конце, скорость по умолчанию 115200;
- частота: рекомендуется **поток 20 Гц** (а не только при изменении) — так приложение видит, что связь жива;
- строки, начинающиеся с `#`, — отладочный вывод, приложение их пропускает.

Также принимаются (на случай, если прошивка уже написана иначе): `"1 0"`, `"1,0"`, `"[1,0]"`, `"bits=10"`,
маска числом `"2"` или одним байтом `0x02` (тогда **бит 0 — канал 1**).

## v0.1 — целевой (этап 1): значения сенсоров

Передаём напряжения всех каналов, маска остаётся отдельным полем. Подробное обоснование —
в `docs/background/Perchatka_sut_idei_i_voprosy.docx`, раздел 3.1.

### BLE-сервис

| Элемент | UUID | Свойства | Назначение |
|---|---|---|---|
| Сервис GLOVE | `6e7a0001-6c6f-7665-2d66-6c6578676c76` | — | реклама и поиск перчатки |
| DATA | `6e7a0002-6c6f-7665-2d66-6c6578676c76` | notify | поток пакетов |
| CONTROL | `6e7a0003-6c6f-7665-2d66-6c6578676c76` | write | команды с ПК (этап 2+) |
| INFO | `6e7a0004-6c6f-7665-2d66-6c6578676c76` | read | JSON: версия прошивки, n_ch, частота |

Имя устройства: `FlexGlove-XX`.

### Пакет DATA (little-endian), 9 + 2·n_ch байт

| Смещение | Тип | Поле | Описание |
|---|---|---|---|
| 0 | u8 | ver | = 1 |
| 1 | u8 | n_ch | число каналов (2, затем 5) |
| 2 | u16 | seq | номер пакета, для подсчёта потерь |
| 4 | u32 | t_ms | время устройства, мс |
| 8 | u8 | bits | маска пальцев, бит 0 — канал 1 |
| 9 | u16 × n_ch | values | напряжения, мВ (0…3300) |

2 канала — 13 байт, 5 каналов — 19 байт: помещается в стандартный BLE-пакет (20 байт). Частота — 100 Гц.

```c
typedef struct __attribute__((packed)) {
  uint8_t  ver;       // = 1
  uint8_t  n_ch;
  uint16_t seq;
  uint32_t t_ms;
  uint8_t  bits;
  uint16_t values[5]; // отправлять 9 + 2*n_ch байт
} glove_packet_t;
```

### Текстовый вариант v0.1 (USB-отладка)

```
seq,t_ms,bits,v1,...,vn
17,12345,1,1200,2100
```

## Правила изменения

1. Любое изменение формата — сначала правка этого файла и согласование в чате команды.
2. Несовместимое изменение — новый номер `ver`.
3. Тест на новый формат — в `host/tests/test_parser.py`.
