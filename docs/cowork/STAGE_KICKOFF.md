# Промпты для запуска этапных чатов

Перед стартом: подключите к чату папку репозитория `flexglove` (последний `main`), создайте ветку этапа.

## Универсальный шаблон

```
Этап N: <название>. Работаем в репозитории flexglove (папка подключена).
1. Прочитай README.md, docs/roadmap.md (раздел этапа N), docs/decisions.md, docs/protocol.md, docs/architecture.md.
2. Задачи этапа: <вставить из roadmap или из ответа планировщика>.
3. Критерий готовности: <вставить>.
4. Контекст от планировщика: <вставить, если есть>.
Сначала дай план работ по шагам и уточняющие вопросы, затем делай. В конце: тесты зелёные,
демо-режим работает, обновлены CHANGELOG, roadmap (статус), decisions (если были решения),
и выдай отчёт по docs/cowork/STAGE_REPORT_TEMPLATE.md.
```

## Этап 2 — готовый промпт

```
Этап 2: MVP на железе. Работаем в репозитории flexglove (папка проекта), ветка stage-2-hardware.
1. Прочитай README.md, docs/roadmap.md (этап 2), docs/decisions.md, docs/protocol.md, docs/architecture.md,
   docs/analysis/2026-10-25-sensor-stream.md.
2. Задачи:
   - проверить приём 5 каналов с реальной перчатки (строка v1;…;v5, 50 Гц) и разобрать, что реально приходит;
   - по записи со сгибами проверить и при необходимости подстроить пороги обработки (processing.py), замерить задержку;
   - профили калибровки по пользователям (выбор оператора в интерфейсе);
   - настройки контроллера в интерфейсе (мёртвая зона, скорость, ограничение сжатия, какие пальцы задают сжатие);
   - <вставить, что выяснилось на встрече с командой>.
3. Критерий готовности: живая перчатка управляет виртуальным захватом и командами у 2–3 человек после калибровки;
   запись со сгибами сохранена в data/recordings и разобрана; все тесты зелёные; демо-режим работает.
Сначала план и вопросы, потом реализация. В конце — отчёт по шаблону.
```

Промпты следующих этапов готовит чат-планировщик по итогам отчёта предыдущего этапа.
