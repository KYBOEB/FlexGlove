# Промпты для запуска этапных чатов

Перед стартом: подключите к чату папку репозитория `flexglove` (последний `main`), создайте ветку этапа.

## Универсальный шаблон

```
Этап N: <название>. Работаем в репозитории flexglove (папка подключена).
1. Прочитай README.md, docs/roadmap.md (раздел этапа N), docs/decisions.md, docs/protocol.md, docs/architecture.md.
2. Задачи этапа: <вставить из roadmap или из ответа планировщика>.
3. Критерий готовности: <вставить>.
4. Контекст от планировщика: <вставить, если есть>.
Сначала дай план работ по шагам и уточняющие вопросы, затем делай. В конце: тесты зелёные,
демо-режим работает, обновлены CHANGELOG, roadmap (статус), decisions (если были решения),
и выдай отчёт по docs/cowork/STAGE_REPORT_TEMPLATE.md.
```

## Этап 1 — готовый промпт

```
Этап 1: связь с реальной перчаткой и протокол v0.1. Работаем в репозитории flexglove (папка подключена), ветка stage-1-protocol.
1. Прочитай README.md, docs/roadmap.md (этап 1), docs/decisions.md, docs/protocol.md, docs/architecture.md.
2. Задачи:
   - отображение напряжений каналов: графики в реальном времени на вкладке «Настройки» (и компактно на главной);
   - запись сессии в data/recordings/<дата-время>.csv (t_host, t_ms, seq, bits, v1..vn) кнопкой «Запись»;
   - ReplaySource: воспроизведение записи через тот же конвейер (выбор файла в интерфейсе);
   - статистика: частота, потери по seq, оценка задержки по t_ms;
   - пороги согнут/разогнут на ПК по напряжениям с гистерезисом (для каналов без маски);
   - доработки BLE по результатам подключения к перчатке Захара: <вставить, что выяснилось>.
3. Критерий готовности: сгибаю сенсор — вижу график на ПК по BLE; запись сохраняется и воспроизводится;
   пороговая маска работает на ПК; все тесты зелёные; демо-режим работает.
Сначала план и вопросы, потом реализация. В конце — отчёт по шаблону.
```

Промпты следующих этапов готовит чат-планировщик по итогам отчёта предыдущего этапа.
