# Отчёт по этапу (шаблон)

> Этапный чат заполняет его в конце работы и выдаёт текстом. Пользователь переносит текст в чат-планировщик.

```
ОТЧЁТ: Этап N — <название>
Даты: <начало> – <конец>        Ветка/PR: <ссылка или имя>        Версия: <x.y.z>

1. Сделано (по критериям готовности):
   - [x] ...
   - [ ] ... (не сделано — почему)
2. Что изменилось в архитектуре/протоколе (файлы, модули):
3. Принятые решения (продублированы в docs/decisions.md):
4. Метрики/проверки: тесты <N passed>; замеры (частота, потери, задержка, точность) — если были.
5. Проблемы и риски, обнаруженные на этапе:
6. Зависимости от команды (что нужно от Лизы/Захара, вопросы):
7. Технический долг (что сделано временно):
8. Предложения на следующий этап:
```
