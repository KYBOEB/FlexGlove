# Проверка 3D-руки и статуса связи — этап 4г

Дата: 21.11.2026. Версия: 0.6.2. Исходный main: `827e75c6e5425b6222d36f7b8a973dd81ac91929` (включает PR №5).
Рабочее дерево перед работой было чистым. Ветка: `stage-4d-fixed-hand-center`.

## Что измерено

Playwright/Chromium на Windows, CSS viewport 1366×768 и 1920×1080, WebGL включён.
Для каждой величины проверены правая и левая glTF, обе запасные модели, раскрытая ладонь,
кулак, крен, тангаж, рысканье, ручное вращение камеры и изменение размера окна.
Опорная точка измеряется независимо от pivot: среднее мировых положений wrist и основания
среднего пальца; для примитивов — локальная середина ладони. Затем точка проецируется камерой
и сравнивается с центром области между верхним и нижним отступами.

| Viewport | Центр в координатах canvas, px | Сочетаний |
|---|---|---|
| 1366×768 | (498.5, 328.5) | 28, включая уменьшение окна до 1166×668 |
| 1920×1080 | (770, 499.5) | 28, включая уменьшение окна до 1720×980 |

В 56 замерах максимальное отклонение менее 0.000001 px (точные значения — в JSON).
Опорные точки модели в сантиметрах: правая glTF `(4.582331, 0.086295, -0.127158)`,
левая glTF `(4.582331, -0.086294, -0.127157)`, примитивы `(4.5, 0, 0)`.
Точки вычисляются один раз по позе покоя. Ни пальцы, ни IMU, ни мышь их не переопределяют.
Камера после отпускания мыши остаётся неподвижной. Отдельных мешей пола/тени в сцене нет;
castShadow/receiveShadow реальной руки сохранены.

Проверены отключение источника (включая ожидание более 3 с без ложной потери приложения),
зависание кадров WebSocket и закрытие WebSocket: устаревшее соединение не остаётся зелёным.
Периодический кадр состояния без источника отправляется раз в секунду; watchdog срабатывает
после 2.5 с без кадров и закрывает соединение для переподключения.

Автоматический тест Node.js использует реальные GLB, GLTFLoader, матрицы three.js и методы Hand3D.
144 сочетания моделей, сгибов и поворотов проверяют неподвижность ладони и нахождение всех
анимированных вершин в сфере кадрирования. Остальные тесты проверяют изоляцию диапазонов демо,
сохранность реальной калибровки, отмену незавершённых замеров и сохранение обычного мастера.

Локальный итог `python -m pytest -q -rs`: **235 passed, 1 skipped**. Пропуск — `pty`-тест
последовательного порта, предназначенный для macOS/Linux. Предупреждение Starlette о будущем
переходе TestClient с httpx на httpx2 не связано с изменениями этапа. Независимое ревью не
оставило открытых замечаний.

## Повторение

1. Установить Playwright отдельно от зависимостей приложения (`python -m pip install playwright`,
   `python -m playwright install chromium`).
2. Запустить текущую ветку на `127.0.0.1:8765`, исходный main на `127.0.0.1:8766`, обе с
   `--demo --ui none --db <отдельная тестовая БД>`.
3. Из корня выполнить `python tools/qa_hand3d.py`. Скрипт меняет только тестовые источники/настройки
   этих двух серверов, перезаписывает снимки и JSON проверки. Для доступа к экземпляру Hand3D
   он инструментирует только HTTP-ответ тестового браузера; рабочий JS глобального QA API не содержит.
4. Обычные тесты: из `host` выполнить `python -m pytest -q -rs` (нужен Node.js).

## Ограничения

Проверка выполнена в headless Chromium с WebGL на этом Windows-компьютере, без физической перчатки.
Это не проверка реального BLE/порта, крепления IMU, задержки оборудования или всех браузеров/GPU.
Дрейф рысканья MPU6050 и сглаживание ориентации сохранены. При фиксации центра ладони раскрытая
кисть занимает меньшую долю кадра, чем при прежнем центре всей кисти: запас нужен для поворотов
пальцев вокруг ладони. На 1366×768 нижние кнопки боковой панели доступны её прокруткой.
Распознаватели и фильтры не менялись; состояние фильтров начинается заново при смене источника.
