# Камера живого предпросмотра 0.8.2

Живой Hand3D копирует направление `main.camera.position - main.controls.target` и `camera.up`
главной руки каждый кадр. Собственная цель остаётся в центре ладони; `fitDistance()` рассчитывает
расстояние и плоскости отсечения по размеру маленького окна. Управление мышью в предпросмотре
отключено, поскольку направление задаётся главным видом.

Сохранённые PNG используют прежний `snapshot()` с `resetView()` и не получают `mirror`.
Распознавание, эталоны и оформление не изменены.

Проверка Chromium на 1366×768 и 1920×1080: вращение главной руки настоящим перетаскиванием мыши,
переход в «Жесты», открытие создания, совпадение направлений и вертикали камеры с погрешностью
менее 1e-8, центрирование ладони и соответствие расстояния собственному `fitDistance()`.
После обучения проверяется исходный фиксированный ракурс PNG. Полная приёмка жестов также прошла;
ошибок JavaScript нет. Node проверяет три размера окна и неизменность камеры источника.

Локально: **290 passed, 1 skipped** (POSIX pty на Windows). CI обеих ОС запускает тот же сценарий.
