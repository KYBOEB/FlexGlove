# Прототип с 2 гибкими сенсорами — проверка связи и разбор записи (этап 2)

> Черновик: заполняется на сессии с перчаткой. После сессии `XX` в имени файла заменить на дату.
> Приложение: ветка `stage-2-prototype`, версия 0.3.0.

## Состав прототипа
| Что | Значение |
|---|---|
| Плата | ESP32-S3 (BLE), прошивка Захара: версия / дата — _заполнить_ |
| Сенсоры | 2 гибких AgNW-сенсора; S1 — палец _…_, S2 — палец _…_ |
| Делитель | резистор _… кОм_; уровень покоя _… из 4095_ (цель — 30–50 % диапазона) |
| MPU6050 | подключён / нет; формат v0.3 подтверждён Захаром: да / нет |

## Порядок сессии (≈ 40 минут)
1. Перед подключением: закрыть Python-программу Захара, на телефоне отключить Bluetooth-приложение
   (ESP32 держит одно подключение).
2. «Настройки → Подключение → Bluetooth LE → Найти устройства» → «Подключить». **Ладонь раскрыта**
   первые секунды (автокалибровка запоминает покой). Если перчатки нет в списке — снять флажок
   «только с именем»; если всё равно нет — USB-кабель и «Порт».
3. «Отладка потока»: переписать в таблицу ниже частоту, формат, «не распознано», пример сообщения.
   Если «не распознано» растёт — скопировать 3–5 примеров «Последнее сообщение» в чат этапа:
   формат добавим в `parser.py` с тестом.
4. «Каналы и пальцы»: назначить S1/S2 реальным пальцам; роли по умолчанию: S1 — сжатие + команды,
   S2 — только команды. Привязки: 11 → «Управление захватом», 01 → «Фиксация захвата».
5. «Сигналы»: «Ладонь раскрыта» (рука неподвижна 1,5 с), затем «Кулак сжат».
6. «Сигналы → Запись по протоколу»: три записи — S1, S2, «все пальцы вместе». Затем в консоли:
   `python tools/analyze_recording.py data/recordings/<файл>.csv --out docs/analysis/img --name prototype-2ch-s1`
   (аналогично `-s2`, `-all`). Таблицы из `*-analysis.md` — в раздел «Разбор записей».
7. Пройти чек-лист ниже.

## Чек-лист
| № | Проверка | Ожидание | Факт | ✓ |
|---|---|---|---|---|
| 1 | Перчатка видна в поиске BLE | имя, RSSI | | |
| 2 | «Отладка потока» | формат `text-values` (или `text-values+imu`), 2 канала, 45–55 сообщ./с, «не распознано» = 0 | | |
| 3 | Предупреждения | нет («частота < 20 Гц», «значение не меняется») | | |
| 4 | Каналы и пальцы | S1, S2 назначены реальным пальцам | | |
| 5 | Автокалибровка при подключении, затем «Ладонь» и «Кулак» | «Откалибровано каналов: 2 из 2» | | |
| 6 | Каждый палец: сгиб 0 → 100 % на графике | плавно, без дребезга 0/1 | | |
| 7 | Комбинации 10 / 01 / 11 | подсвечивается нужная карточка | | |
| 8 | ARM жестом 11 | «Управление захватом: разрешено» | | |
| 9 | Сжатие ведёт захват (полусжатие ≈ 50 %) | команда захвату следует за рукой | | |
| 10 | Кулак при ARM, держать 3 с | команды **не** переключаются, в журнале «Жест … не выполнен» | | |
| 11 | Полусжатие + удержание S2 ≥ 1 с | ARM снимается | | |
| 12 | Выключить перчатку | «Нет связи», захват заморожен, ARM снят, «Переподключение 1 из 3…» | | |
| 13 | Включить перчатку в течение ~7 с | «переподключено», данные снова идут | | |
| 14 | Запись CSV | открывается в Excel, колонки S1, S2 (и IMU, если есть) | | |
