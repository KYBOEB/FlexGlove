# Локальные аудиофразы

Положите сюда три своих MP3-файла. Названия произвольные, например по смыслу ваших фраз.
Сами записи в репозиторий не входят. Затем в приложении откройте «Настройки → Обучаемые жесты»,
выберите файл для каждого жеста и нажмите «Проверить аудио». Список обновляется автоматически.

Звук воспроизводится устройством по умолчанию компьютера, где запущен Python.
«Остановить аудио» прерывает текущий файл и очищает очередь. Файлы не выдаются браузеру.
После копирования файла отдельно проверьте слышимость, правильность фразы и кнопку остановки.
Автоматические тесты работают с заглушкой и не подтверждают слышимость реальных MP3.
